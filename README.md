# Cloud Range

AWS and Azure, side by side, from zero → certified → senior cloud engineer.
Offline-capable PWA for iPhone and laptop.

## Two independent locked tracks
**AWS** — Cloud Practitioner (CLF-C02) → Solutions Architect Associate (SAA-C03) → Pro track
**Azure** — Azure Fundamentals (AZ-900) → Azure Administrator (AZ-104) → Pro track (AZ-700/500/305 topics)

Every step: lesson, flashcards, explained practice questions, labs and a gate test.
Finish the labs and score **over 90%** to unlock the next step in that track.
Capstones mirror the real exams (question count, time limit, official domain weights).

## Labs
Real **AWS CLI** and **Azure CLI** syntax against a simulated cloud with a live resource map:
VPCs, subnets, route tables, internet/NAT gateways, security groups, EC2, S3 hardening, IAM,
CloudWatch alarms; resource groups, locks, RBAC, storage hardening, VNets, NSG priority
troubleshooting, VMs, Azure Monitor alerts. Reachability is computed from your configuration.

## Save & restore
Each passed step gives a checkpoint phrase (e.g. `AWS01-FIRST-REGION`, `AZ01-CONSUMPTION-MODEL`).
Type your latest phrase per track into **Save → Restore** on any device.

## Deploy
Files at the repo root → Settings → Pages → Deploy from branch `main` / root.
Open `https://wphilippskylar-bit.github.io/cloud-range/` in Safari → Share → Add to Home Screen.
